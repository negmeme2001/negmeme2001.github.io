CoverPilot

An insurance customer assistant that cites its sources and says 'not covered' when it should.

  • LangGraph agent: guard → retrieve → agent ⇄ tools → answer, streamed over SSE.
  • Citations come from the retriever, never from the model's text; a relevance floor (cosine ≥ 0.33) handles out-of-scope questions.
  • Tools (get_claim_status, submit_claim) with Pydantic validation; 82 unit and 12 integration tests; zero-cost mode on Groq.
